BubblePopWorld — Main Sell Kiosk Sign Mesh

Fichier:
- BubbleSell_MainSign.obj

Import dans Roblox Studio:
1. Ouvre le vrai projet Popdanielpop.
2. Va dans Avatar ou Home > Import 3D.
3. Choisis BubbleSell_MainSign.obj.
4. Importe-le comme MeshPart.
5. Place-le au-dessus du kiosque.
6. Ajuste l'échelle si nécessaire.
7. Recommandation:
   - Material: SmoothPlastic ou Metal
   - Color: bleu marine foncé
   - Ajouter un SurfaceGui sur la face avant
   - Texte: VENDRE LES BULLES
   - Ajouter une bordure Neon cyan/violet avec des Parts fines séparées

Remarque:
Le texte n'est pas intégré au mesh. Il doit rester en SurfaceGui pour être net et facilement modifiable.
